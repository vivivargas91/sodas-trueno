# Que es?
Esta es una aplicacion para registrar sodas de las 7 provincias de CR y tener un registro 

# Como se usa
completar el formulario para registrar la visita a la soda.
se puede registrar como favorita o se puede eliminar 
tiene un registro de lo que se pidío, provincia, calificacion de estrellas y si volveria
se puede ver un resumen de los formularios de las sodas
